# Security Policy

ZigGuard operates close to developer tools, repositories, shell commands, CI systems, and AI agents. Security-sensitive behavior is therefore treated as part of the product contract.

## Reporting a vulnerability

Please do not open a public GitHub issue for a suspected vulnerability.

Use GitHub's private vulnerability reporting / Security Advisory flow when it is available for this repository. If it is not available, contact the repository owner privately before public disclosure.

## Security principles

- least privilege;
- local/offline operation where possible;
- no secret collection by default;
- explicit approval for destructive behavior;
- deterministic, reviewable generated files;
- fail closed for unsupported security-sensitive policies;
- untrusted repository content must not be executed simply for analysis.

Supported-version details will be added with the first release.
