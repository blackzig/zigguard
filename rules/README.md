# Rule Catalog

ZigGuard rules are tool-neutral policy semantics.

A rule should eventually define:

- stable rule ID;
- human-readable purpose;
- accepted values/actions;
- security implications;
- adapter capability expectations;
- local enforcement strategy, when applicable;
- fixtures/tests.

The initial v0.1 rules are intentionally limited to scope control, security, quality, and Git safety. See [../docs/policy-spec.md](../docs/policy-spec.md).
